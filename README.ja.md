# Mac OBS Beauty · Mac 用 OBS 美顔プラグイン

[中文](README.md) · [English](README.en.md) · [ダウンロード](https://github.com/TIMEKB/mac-obs-beauty/releases/latest) · [AI 向け導入ガイド](AGENTS.md)

Apple Silicon Mac の OBS で、公式 Mac 版 Douyin Live Companion（抖音直播伴侣）のローカル美顔エンジンを利用するプラグインです。ソース選択、美肌・顔や体形の調整、メイク、フィルター、プリセット、元映像との比較をドックパネルから操作できます。公開バージョンは **0.8.0** です。

## ダウンロードしてインストール

1. [Releases](https://github.com/TIMEKB/mac-obs-beauty/releases/latest) から **`mac-obs-beauty-0.8.0-macos-arm64.pkg`** をダウンロードします。
2. OBS を終了し、PKG をダブルクリックして macOS の手順に従ってください。**標準の `obs-live-beauty.plugin` をユーザーの OBS フォルダーに直接導入します。独立 `.app`、依存確認ウィザード、二回目のプラグイン導入操作は不要です。**
3. OBS を再起動し、「ドック / ツール → **直播美颜**」でソースを選び、**添加到来源** をクリックします。**按住对比** は元映像との比較です。

Apple Silicon（M シリーズ）Mac、macOS 13 以降に対応し、OBS 32.2.1 arm64 で検証しています。ZIP、標準 `.plugin`、任意の `install.command`、`SHA256SUMS` も用意しています。

美顔処理には本機の公式 Mac 版直播伴侣の実行ライブラリを利用します。プラグイン導入時の前提チェックは行いません。素材が不足する場合だけ、OBS 内で案内し、「ツール → **美颜运行资源…**」から準備できます。準備済みならそのまま使用でき、不足時は元映像を維持します。初回の素材準備にはネット接続が必要です。

「ツール → **识别点诊断…**」またはドック下部の **识别点** で、実際の106点、番号、点の範囲、フリーズ、処理前後の比較を確認できます。マークは診断ウィンドウだけに表示され、配信・録画には入りません。本公開版は美顔のみで、キャプチャーカード、Wink、FaceBetter は含みません。
対応バージョンは **OBS 32.2.1（arm64）と直播伴侣 10.0.0 / 10.0.4** です。実行素材の準備ツールは検証済みの公式互換バージョンを案内します。美顔エンジンを読み込むため、公式直播伴侣アプリを削除しないでください。インストーラー画面とプラグインの主な操作表示は現在中国語です。

バイナリはアドホック署名、PKG は未署名です。Developer ID 署名と Apple 公証は行っていません。macOS にブロックされた場合は、入手元と Release のチェックサムを確認したうえで「システム設定 → プライバシーとセキュリティ → このまま開く」から許可してください。Gatekeeper 全体を無効にする必要はありません。[三言語の初回インストールガイド](README.install.md) も参照してください。

OBS の配信・録画を終了し、自分で OBS を閉じてからインストールしてください。インストーラーが OBS を強制終了することはありません。ダウンロードに失敗した場合は接続を確認して再試行するか、インストーラーの公式サイトボタンを利用してください。未検証の最新版に置き換えると互換性チェックに失敗する場合があります。

## AI による導入

通常はソースをビルドせず、Release を使います。インストーラーの内部実行ファイルは `obs-live-beauty-installer` です。ZIP を解凍し、`--assets-dir` でそのディレクトリーを指定して `--plugin-only --install --non-interactive --json`、次に `--plugin-only --check --json` を実行してください。実行素材を調べる場合は `--plugin-only` を省きます。

不足依存は JSON の `dependencies` に状態、公式ダウンロード URL、次の手順が表示されます。独自パスには `--obs-app PATH` と `--app PATH` が使えます。詳細は [AGENTS.md](AGENTS.md) を参照してください。初回の `ready=false` は、まだプラグインや素材がない状態でも発生します。インストール失敗とは区別してください。

通常は既定の素材フォルダーを使います。`--resource-dir` を変更した場合は、OBS パネルでソースに処理を追加し、下部の **资源目录** からそのフォルダーを指定する必要があります。

## 削除

OBS を終了し、`~/Library/Application Support/obs-studio/plugins/obs-live-beauty.plugin` だけを削除してください。素材が不要になった場合は `~/Library/Application Support/obs-live-beauty/engine-resources` を別途削除できます。OBS 全体のプラグインフォルダーやシーン設定は削除しないでください。

インストール失敗時は元のファイルへの復元を試みます。復元にも失敗した場合は `errors` に残された `.previous` パスが表示されます。
